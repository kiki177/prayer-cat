# 礼拜喵 v2.5.0 验证记录

验证日期：2026-09-08。

## 已验证

- 原生源码 arm64、x86_64 编译成功；两架构二进制最低系统版本均为 macOS 13.0。Intel 为交叉编译，未做 Intel 实机运行。
- 33 项核心检查通过：新闻日期/过滤、每日标记持久化、RSS/Atom 解析、记忆与备忘检索等。
- 最终 macOS 13 构建使用内置 Qwen3-0.6B 实际推理：正确回答测试用户姓名；取消测试通过。本次推理约 2.6 秒，仅代表测试机器与该短问题。
- 此前在临时签名沙盒应用中实际完成桌面聊天，并取得带当天日期和来源链接的新闻。
- 聊天组件浅色/深色及不同宽度渲染检查通过。
- 试用包为 Universal 2，内置模型；无需 API key、Ollama 或 Node.js。

## 使用

解压试用包，在 macOS 13 或更新版本打开应用，从菜单进入聊天与陪伴设置。新闻和记忆默认关闭，需要用户自行启用。试用包仅临时签名，未经公证，系统可能阻止打开；正式分发需要发行者签名。试用版使用独立应用标识，不覆盖原正式版数据。

## 尚未完成的发布验收

新闻仅有有限国家和国际专题来源，不能保证任何城市每天都有 2–3 条关键新闻。小模型的自然程度与知识准确性有限。桌宠动作复用了现有素材，专用新动画帧未完整补齐。新增界面尚未完整提供阿语/乌尔都语。

需要真实 Intel/macOS 13、多显示器、耗电与长时间运行、下载异常、记忆删除等完整实机验收；发行者还需提供正式证书、真实隐私/支持网址并确认原素材和新闻使用权。详细清单见源码 RELEASE-GATES.md。此版本不能视为已达到全部上架要求。
