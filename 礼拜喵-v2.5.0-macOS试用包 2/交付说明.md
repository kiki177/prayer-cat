# 礼拜喵 v2.5.0 交付说明

这次在原生 macOS 2.4.1 源码上加入了本地聊天、新闻、记忆和桌面互动，移除了 ChatGPT 网页入口与 OpenAI API 功能。

- 试用包内置约 640 MB 的免费 Qwen3 轻量模型，用户不需要安装 Ollama、Node.js、填写密钥或注册；更大模型可在应用中下载。
- 新闻在每天首次启用/打开时尝试自动汇报，退出重开不重复；只展示当天可验证的原文标题、时间、出处链接，不拿旧闻凑数。
- 桌面猫有鼠标观察/扑跳、窗口边缘停留、睡觉、戳后生气、抚摸、求摸及奔跑状态；专用新动作美术帧尚未完整补齐。
- 本地观察可沉淀长期记忆，并检索应用内备忘。用户可以关闭、修改、清除记忆。

**这是工程与试用交付，不是可直接提交且保证过审的成品。** 新闻国家/城市覆盖还有限，新增界面阿语/乌尔都语回退英文，小模型质量和不同硬件的性能还需进一步产品验收。正式签名、真实隐私/支持网址、素材及新闻授权、实机回归仍是上架前门槛。

完整使用与构建方法见源码内 README.md；发布差距见 RELEASE-GATES.md。试用版与原正式版本使用不同 bundle ID，不会覆盖原应用数据。
