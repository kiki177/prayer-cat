## 中文

**礼拜喵**是一款面向穆斯林用户的 macOS 备忘与知识空间应用。

### 主要功能

- 中文、英文、阿拉伯语和乌尔都语界面
- 斋月模式
- 备忘与知识空间
- 礼拜喵主体猫形象应用图标
- 充值礼包功能已下线

### 最新版本

**macOS v2.3 — 斋月模式 App Store 准备版**

## English

**Prayer Cat** is a macOS reminder and personal knowledge-space app designed for Muslim users.

### Key features

- Chinese, English, Arabic, and Urdu interfaces
- Ramadan Mode
- Reminders and personal knowledge space
- App icon featuring the Prayer Cat mascot
- Recharge and gift-package features have been discontinued

### Latest version

**macOS v2.3 — Ramadan Mode, App Store-ready build**

Download: [Prayer Cat macOS v2.3](./礼拜喵-macOS-v2.3-斋月模式-AppStore准备版.zip)

Unzip the file and move the app to the Applications folder. Apple Developer signing, notarization, and App Store Connect review are still required for App Store distribution.

## العربية

**Salah Cat** هو تطبيق لنظام macOS مخصص للمستخدمين المسلمين، يجمع بين التذكيرات ومساحة المعرفة الشخصية.

### الميزات الرئيسية

- واجهات باللغات الصينية والإنجليزية والعربية والأردية
- وضع رمضان
- التذكيرات ومساحة المعرفة الشخصية
- أيقونة تطبيق مستوحاة من شخصية القط الرئيسية
- تم إيقاف ميزات الشحن وباقات الهدايا

### أحدث إصدار

**macOS v2.3 — وضع رمضان، إصدار مُجهز لمتجر App Store**

التنزيل: [Salah Cat macOS v2.3](./礼拜喵-macOS-v2.3-斋月模式-AppStore准备版.zip)

بعد فك الضغط، انقل التطبيق إلى مجلد Applications. يتطلب النشر في متجر App Store توقيع Apple Developer والتوثيق ومراجعة App Store Connect.
