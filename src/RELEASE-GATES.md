# 正式上架前的发布门槛

当前交付是可编译、包含实际本地推理的工程及试用包，**不是已经通过 Apple 审核的发行包**。面向所有用户的架构已采用原生客户端、内置推理、用户隔离的本地存储和无需密钥的流程；以下事项仍不能省略。

## 必须由发行者提供/确认

- Apple Developer 团队、Bundle ID、Apple Distribution 证书及相应签名/Provisioning Profile。临时签名不能替代 App Store 分发。
- 真实的隐私政策公开网址、支持网址、联系信息；App Store Connect 隐私问卷、年龄分级、审核说明。应用本身不上传聊天或记忆；AlAdhan、MapKit、新闻源和模型 CDN 的请求仍需如实说明。
- 原 2.4.1 猫咪/图标素材的商业分发权利。仓库中的原文件不能证明发行者持有版权。
- 新闻来源许可复核与目标市场覆盖验收。当前英国/新西兰和全球专题来源有限，不应宣传为每个城市均有 2–3 条关键时事。联合国与其他媒体如需启用，应取得适用许可。
- 在真实 Intel 与 Apple Silicon 设备、macOS 13 和最新系统上跑完整回归；本机已跑 Apple 芯片实际推理，Intel 当前为交叉编译验证，不能冒充 Intel 实机验收。
- 中文/英文以外新增界面的人工本地化，以及宗教相关回复、多轮记忆、情绪陪伴的质量评估。小模型的输出控制不是经过完整验证的内容安全系统；不得未经评估发布到儿童类别。

## 已落实的工程措施

- 不要求用户 API key、终端、Ollama、Node.js 或注册。
- 推理代码编译入二进制，模型固定提交/哈希，额外下载仅为模型数据。
- App Sandbox、network.client、原有位置用途声明；没有录屏、辅助功能、麦克风权限和输入注入。
- 记忆默认关闭、可查看修改清除；关闭记忆停止生成并清空上下文；备忘文件独立保留。
- 今日新闻使用来源时间和所在地时区，持久化每日自动尝试标记，不重复启动自动汇报，失败/空结果不虚构。
- 含 PrivacyInfo.xcprivacy、模型与 llama.cpp 开源许可、来源归属说明。

## 已知测试边界

已通过核心自动化检查、真实 0.6B 推理/取消、Universal 两架构编译和临时签名沙盒应用启动；在原生聊天框观察到真实回复与输入恢复。新闻在应用中取得带出处和当天日期的真实条目。

仍需长时间内存/耗电测试、低磁盘/断网/下载中断的系统级验收、多显示器与窗口最小化/Spaces/全屏的完整交互验收、关闭与删除记忆的用户级回归，以及 Apple Distribution 签名后的正式沙盒与 App Store 验证。测试报告应区分已跑过的检查与待做项目。

参考 Apple 规则：https://developer.apple.com/app-store/review/guidelines/
